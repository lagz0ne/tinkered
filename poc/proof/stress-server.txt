## tinker prepare lies on a route conflict

It says it wrote the route tree, and exits 0.
Doctor check 3 then says "run tinker prepare".
That advice cannot fix it. Check 7 names the cause.

Repro:

```bash
cd /tmp/stress-rerun/server/probes/route-collision
# has src/routes/api.health.ts
# with createFileRoute("/api/health")
tinker prepare; echo "EXIT $?"
ls .tinker
tinker doctor
```

Output:

```text
Error: Conflicting configuration paths …
  "/api/health", "/api/health".
tinker prepare: wrote .tinker/tsconfig.json,
  .tinker/base.json, .tinker/routeTree.gen.ts
EXIT 0
base.json  tsconfig.json  violations.json
fail  3 generated folder
      .tinker/routeTree.gen.ts is missing;
      run tinker prepare
fail  7 routes
      src/routes/api.health.ts:3 takes
      /api/health, a base route
```

Cause: `bin/tinker.mjs` prints the route tree
as written without checking the file.
Log: logs/raw/probe-route-collision.prepare.log
