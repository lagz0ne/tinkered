# Flight trial data license

This data contains information from [OpenFlights](https://openflights.org/data.php).
OpenFlights credits OurAirports and DAFIF for airports.
It credits Airline Route Mapper for routes.

The source subset and generated flight database are under the
[Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Rights in each entry are under the
[Database Contents License 1.0](https://opendatacommons.org/licenses/dbcl/1-0/).
Keep this notice with copies and public results.

Routes stopped updating in June 2014.
They are historical data.
Schedules, fares, seats, and suppliers are made up for this trial.
They are not real offers or current airline service.

The pinned commit and source hashes are in `manifest.json`.
The subset and the code that makes the added data ship beside this notice.
